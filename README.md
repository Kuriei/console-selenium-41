## Objetivo
Automatizar testes de um formulario web utilizando C#, Selenium WebDriver e MSTest.

## Tecnologias
- C# e .NET 10
- MSTest
- Selenium.WebDriver
- Selenium.Support
- Google Chrome

## Testes implementados
1. Cadastro completo: preenchimento dos campos e validacao da mensagem de sucesso.
2. Dropdown e Datalist: selecao da opcao Two e preenchimento com Seattle.
3. Checkbox, Radio e Color Picker: alteracao dos estados e envio do formulario.

## Executar os testes
dotnet test
